1. What is a neural network?

A neural network is a model made of connected computational units called neurons, organized into layers. It learns patterns by adjusting weights and biases during training.

Input layer receives metrics; hidden layers learn intermediate patterns; output layer produces a prediction such as a failure score.

2. A single artificial neuron

First, multiply each input by its weight, add the results and a bias, then apply an activation function.

z = w₁x₁ + w₂x₂ + b
a = f(z)

3. Activation functions

Activation functions transform a neuron's weighted sum. Nonlinear activations allow stacked layers to learn complex nonlinear relationships.

Step

Threshold-style output, such as 0 or 1. Useful for the original perceptron intuition.

Sigmoid

Maps a value to a range between 0 and 1. Often used at binary-classification output layers.

σ(z) = 1 / (1 + e⁻ᶻ)
ReLU

Returns zero for negative values and the input for positive values. Common in hidden layers.

ReLU(z) = max(0, z)

The graph is a conceptual sketch; the key point is the shape and output behavior, not exact axis scaling.

4. Forward pass

A forward pass moves inputs through each layer to calculate an output. During training, the prediction is compared with the known label using a loss function. Parameter updates happen through optimization; backpropagation will be covered in a later lesson.

  1. Input metrics enter the network.
  2. Neurons calculate weighted sums plus bias.
  3. Activation functions transform values.
  4. Subsequent layers receive those outputs.
  5. The output layer produces a prediction.
Example: an output score of 0.87 can be interpreted as an estimated failure probability only if the model and its output are appropriately trained and calibrated.
