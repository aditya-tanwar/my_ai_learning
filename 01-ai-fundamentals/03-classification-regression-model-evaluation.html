Classification, Regression & Evaluation

Choose the right prediction task and understand confusion matrices, precision, recall, F1 and thresholds.

1. Classification vs regression

Classification

Predicts a category or class.

Example: pod failure = Yes / No; healthy / warning / critical.

Regression

Predicts a numeric value.

Example: expected memory consumption = 3.8 GiB.

2. Confusion matrix

For binary classification, compare predicted classes with actual outcomes.

  • TP: actual failure, predicted failure.
  • FP: actual healthy, predicted failure.
  • FN: actual failure, predicted healthy.
  • TN: actual healthy, predicted healthy.

3. Evaluation metrics

MetricFormulaQuestion answered
Accuracy(TP + TN) / TotalHow often was the prediction correct overall?
PrecisionTP / (TP + FP)When we alert, how often are we right?
RecallTP / (TP + FN)Of actual failures, how many did we catch?
F12 × (Precision × Recall) / (Precision + Recall)Balances precision and recall

Worked example: TP=40, FP=10, FN=20, TN=130, total=200.

Accuracy can mislead on imbalanced datasets. Choose metrics based on the cost of false alarms versus missed failures.

4. Thresholds and trade-offs

A classifier may output a score such as 0.82. With a threshold of 0.5, it predicts failure. Lowering the threshold generally catches more positives (higher recall) but may create more false alarms. Raising it may reduce false alarms but miss more failures.

Knowledge check & interview prompts

Explain classification versus regression, calculate precision and recall from a confusion matrix, and describe how lowering a threshold changes false positives and false negatives.

Remember: Recall = TP / (TP + FN). It measures how many actual positive cases were detected.
