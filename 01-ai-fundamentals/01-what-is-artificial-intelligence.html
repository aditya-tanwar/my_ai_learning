What Is Artificial Intelligence?

Understand AI, ML, deep learning, generative AI, and where infrastructure fits in the lifecycle.

Learning objectives

Distinguish AI, ML, DL, GenAI and LLMs; compare rule-based programming with machine learning; recognize supervised, unsupervised and reinforcement learning; connect the AI lifecycle to infrastructure.

1. The AI family tree

AI is the broad field. Machine learning is one approach within AI; deep learning is a family of ML methods based on neural networks. Generative AI creates content, and LLMs focus on language.

Nuance: this is a simplified learning map, not a strict taxonomy. GenAI also includes image, audio and video models; AI includes methods that are not ML.

2. Traditional programming vs ML

Traditional programming

Input + written rules
        ↓
      Output

Example: if cpu > 90: alert(). The engineer defines the rule.

Machine learning

Examples + algorithm
        ↓ training
    Trained model
        ↓ new input
     Prediction

The model learns statistical patterns from examples.

3. Three common learning approaches

Supervised learning

Uses labelled examples: metrics plus known pod-failure outcome. Common tasks: classification and regression.

Unsupervised learning

Uses unlabelled data to discover groups or unusual observations, such as anomalous workloads.

Reinforcement learning

An agent takes actions in an environment and learns from rewards or penalties, such as resource allocation in a simulator.

4. AI lifecycle and infrastructure

Infrastructure spans ingestion, compute, storage, registries, serving, observability, security and cost. Think of a model artifact as a deployable artifact with extra lineage and evaluation requirements.

Key takeaways

  1. ML is a subset of AI; deep learning is a subset of ML.
  2. Supervised learning uses labels; unsupervised learning finds structure; reinforcement learning learns from rewards.
  3. Production AI needs reliable data, training, artifacts, inference, monitoring, security and cost controls.

Knowledge check

Explain the AI/ML/DL relationship, contrast rules with learned patterns, and give one infrastructure example for each learning approach.
