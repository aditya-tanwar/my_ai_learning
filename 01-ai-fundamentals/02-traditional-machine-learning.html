2. Training, validation and test

Illustrative split of 10,000 records. Real split choices depend on dataset size, class balance, time and grouping.

SplitPurposeUpdates learned parameters?
TrainingLearn patternsYes

Keep the test set held out until final evaluation. Repeatedly tuning against it leaks information into model selection.

3. ML workflow

DevOps parallels include data pipelines, containerized training jobs, MLflow experiment tracking, object storage/model registries, Kubernetes serving, and observability.

4. Training vs inference

Training

Uses historical examples and labels to learn parameters. Produces a model artifact.

Inference

Uses the trained model and new inputs to produce predictions. Often exposed as an API or service.

5. Data leakage

Leakage occurs when information unavailable at real prediction time influences training or evaluation. Example: using a post-failure event field to predict whether the pod will fail. The model appears excellent offline but cannot use that signal legitimately in production.
